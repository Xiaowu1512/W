# 02 构建链路数据

- 写入日期：2026-10-17
- 修改日期：2026-10-17
- 本次内容：把三份年度城市接续记录汇总为固定81城之间的有向链路，并生成衰减权重版本和逐条计数版本。

## 1. 这一步做什么

这一步读取步骤01生成的三份年度农机城市接续数据。只保留起点和终点都属于固定81城的记录，然后按“年份、起点城市、终点城市”汇总。

2021、2022、2023年分别计算。`A→B`和`B→A`是两条不同链路，不会合并。

## 2. 两个权重版本

### 主版本：衰减链路

同一方向城市对的所有`衰减权重`相加：

```text
链路权重 = 该方向城市对所有接续记录的衰减权重之和
```

例如，`A→B`有一条一级边和两条二级边，衰减权重分别为1、0.5、0.5，则主版本的链路权重为2。

### 备用版本：计数链路

每条接续记录都计1：

```text
链路权重 = 该方向城市对的接续记录数
```

上面的例子有3条记录，因此备用版本的链路权重为3。备用版本已经生成，但当前不作为主版本使用。

## 3. 重复记录怎样计算

同一台农机同一年多次形成同一方向城市对时，每条接续记录都参与计算，不先按农机去重。

文件同时保留`涉及农机数`，用于查看该链路涉及多少台不同农机，但它不参与本次权重计算。

## 4. 当前没有使用的筛选

本步骤没有根据以下条件删除记录：

- 时间间隔长短；
- 时间冲突；
- 一级边或多级边；
- 是否回访；
- 是否同城端点。

同城端点继续保留，并用`是否同城边`和`同城端点记录数`标出。一级边和二级及以上边分别计数，避免把所有关系都理解为相邻城市间的直接移动。

没有出现过的城市对不写入输出文件。它们的权重可以理解为0，但本步骤不主动补出零权重行。

## 5. 输入文件

- `Data/03_有向边数据/2021年农机城市接续.csv`
- `Data/03_有向边数据/2022年农机城市接续.csv`
- `Data/03_有向边数据/2023年农机城市接续.csv`
- `Data/02_筛选后81城数据/citys_2023_1.csv`
- `Data/data_manifest.csv`，只用于核对三份年度输入的行数和文件指纹。

输入的时间范围均为当年5月1日至6月25日。城市名称去掉首尾空格后与固定81城名单精确匹配，不进行模糊匹配。

## 6. 输出文件

主版本：

- `Data/04_城市链路数据/2021年衰减链路.csv`
- `Data/04_城市链路数据/2022年衰减链路.csv`
- `Data/04_城市链路数据/2023年衰减链路.csv`

备用版本：

- `Data/04_城市链路数据/2021年计数链路.csv`
- `Data/04_城市链路数据/2022年计数链路.csv`

所有CSV均使用UTF-8-SIG编码。

## 8. 代码检查

Notebook会检查：

- 固定城市名单是否为81个唯一城市；
- 输入文件的行数和文件指纹是否与数据清单一致；
- 必要字段是否存在且没有缺失；
- 边级和衰减权重公式是否一致；
- 输出是否只含固定81城；
- 每个年份的有向城市对是否唯一；
- 一级边记录数与二级及以上边记录数能否还原接续记录总数；
- 主版本权重合计能否还原81城内输入记录的衰减权重之和；
- 备用版本权重合计是否等于81城内接续记录数；
- 两个版本的城市对是否完全一致；
- 输出文件能否正常读回，编码是否为UTF-8-SIG。

代码文件为`build_city_links.ipynb`，可以从头到尾独立运行。默认不覆盖已有结果；确认重跑时设置环境变量`CITY_LINK_ALLOW_OVERWRITE=1`，代码会先备份旧结果。
