## 2. 先删除哪些接续记录

正式决定见`DECISIONS.md` D008、D009。在第二步按每一条接续记录分别判断：

1. 删除`时间间隔小时<0`的行。它等于终点进入时间减起点离开时间。例如A市10:00结束、B市09:30开始，间隔为−0.5小时，此条A→B删除。等于0正常保留；不设置最大正时间间隔。
2. 删除`起点城市=终点城市`的行，如A→A、C→C。不再把它们作为一种研究边单列。
3. 一行同时满足两类条件时，只删一次，删除记录注明两个原因。不删除整台农机、不连带删除其他边。

不修改原始GNSS、第一步代码或第一步CSV。第一步保留完整候选接续；本步骤另存筛选后的三份接续数据。筛选数据保留原字段、原访问序号、原边级、原衰减权重和回访标记，不重新排列访问、不拼接新边。

## 3. 重复城市怎样计入权重

完整顺序为`A₁-B₂-C₃-D₄-C₅-E₆-A₇`，下标是访问位置。只排除A₁→A₇、C₃→C₅这样的同城边，不删除C₅、A₇这些访问位置。

| 接续记录 | 中间经过的访问 | 边级 | 衰减权重 |
| -------- | -------------- | ---: | -------: |
| 第一次C→E，即C₃→E₆ | D₄、C₅ | 3 | `0.5²=0.25` |
| 第二次C→E，即C₅→E₆ | 无 | 1 | `0.5⁰=1` |

D₄→C₅、E₆→A₇这样的直接回流正常保留，只要时间符合条件。不能因为删除C→C就跳过第二次C，把第一次C→E改算成0.5。代码中有上述例子的检查。

## 4. 汇总两种链路权重

从筛选后接续中选择两端都在81城的记录，按“年份、起点城市、终点城市”汇总。A→B和B→A分开；同一农机重复形成同一城市对时，每行都参与计算。

- 主版本：同方向城市对全部保留接续记录的衰减权重之和。
- 备用版本：同方向城市对每条保留接续记录计1，当前不作为主版本使用。

上面两条C→E如果时间符合、C和E都在81城，主版本合计1.25，备用版本合计2。没有出现过的城市对不补零行。
