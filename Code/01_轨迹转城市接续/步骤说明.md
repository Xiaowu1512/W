# 01 轨迹转城市接续

- 写入日期：2026-10-16
- 修改日期：2026-10-16
- 本次修改：首次建立并全量运行三年农机城市候选接续数据生成流程。

## 1. 说明

本步骤把三份田间作业段轨迹按年份、农机和时间整理为城市访问序列，再在同一未被关键缺失打断的链段内，为每一对前后访问位置生成候选有向接续记录。

本步骤保留全部轨迹城市，不预先限制为固定 81 城；2021、2022、2023 分开处理，绝不跨年连边。输出描述时间序列中的接续或下游关联，不能单独证明真实直接迁移，更不能解释为因果效应。

## 2. 参数

| 参数 | 正式设置 | 说明 |
| ---- | -------- | ---- |
| 年份 | 2021、2022、2023 分开 | 同一 `did` 跨年不连接 |
| 城市范围 | 全部 `center_location` | 不限于 81 城 |
| 衰减基数 | 0.5 | `衰减权重 = 0.5^(边级-1)` |
| 最大时间间隔 | 未设置 | 不按间隔删除；保留`时间间隔小时`与冲突标记 |
| 关键字段 | `did`、`date`、`start_time`、`end_time`、`center_location` | 不填补；无法定位或排序的关键缺失会停止运行；城市缺失但时间有效时作为断点 |
| 排序 | `date`、`start_time`、`end_time`、`center_time`、`info_id`、`id`、原始行号 | 原始行号仅用于最终稳定打破并列 |

## 4. 处理

1. 分年、分农机稳定排序。
2. `center_location` 缺失的记录不填补、不进入访问或边，并打断其前后链；连续缺失记录作为一个缺失块。
3. 链段内连续同城记录合并为一次访问：进入时间取该块最早 `start_time`，离开时间取该块最晚 `end_time`，原始记录数保留。离开后再次回到同城形成新的访问。
4. 对链段内访问位置 `i<j` 生成一条候选边。同一农机多次出现相同城市对时不去重。
5. `边级=j-i`；一级边是相邻访问，二级边跨过 1 个访问，三级边跨过 2 个访问，N 级边跨过 N−1 个访问；`跨越城市数=N-1`，这里按中间访问位置计数，不按唯一城市名计数。
6. 保留回访事实：起点/终点是否回访、终点城市访问序次、直接回流边及同城端点边。`是否直接回流边`仅指一级边且目标访问城市在当前链段内此前出现过；最终研究中的“回流边”口径仍留待后续决定。

## 5. 检查

代码写出前执行以下硬检查：

- 每链 L 次访问必须生成 `L(L-1)/2` 条边；一级边必须为 `max(L-1,0)` 条。
- 候选主键`年份+农机编号+链段编号+起点访问序号+终点访问序号`唯一。
- 起点访问序号小于终点访问序号，边级为正整数，`跨越城市数=边级-1`，权重逐行符合公式。
- 输出端点城市无缺失；一级边不得出现同城端点。
- 连续同城合并后的相邻访问城市不同；访问的原始记录数之和能回算有效输入行数。
- 输出 CSV 能按 UTF-8-SIG 读回，字段顺序和行数一致。
- 三年分开运行，输出哈希在一次独立重跑中完全一致。
