# 01 轨迹转城市接续

- 写入日期：2026-10-16
- 修改日期：2026-10-17
- 本次修改：把城市为空的5行记录当作噪音删除，并保存一份删除明细。其余记录继续按时间排列。

## 1. 这一步做什么

这一步把每台农机的田间作业记录按时间排好，整理出它先后到过的城市，再生成前后城市之间的接续记录。

2021、2022、2023年分开处理，不会跨年连接。保留全部有名称的轨迹城市，不提前限制为81城。

输出只能说明城市出现的先后关系，不能证明农机一定从起点直接开到终点，也不能证明因果关系。

## 2. 主要设置

| 项目 | 当前设置 | 简单说明 |
| ---- | -------- | -------- |
| 年份 | 2021、2022、2023分开 | 同一台农机不跨年连接 |
| 城市范围 | 全部有名称的城市 | 不限于81城 |
| 城市为空的记录 | 删除 | 共5行；明细单独保存 |
| 删除后的连接方式 | 剩余记录继续按时间排列 | 删除行前后的有效城市可能重新相邻 |
| 连续同城 | 合并 | 连续多条同城记录算作一次访问 |
| 再次返回同城 | 保留 | 离开后再回来算作新的访问 |
| 权重 | 每远一级减半 | 一级为1，二级为0.5，三级为0.25 |
| 最大时间间隔 | 暂不设置 | 目前不因为时间间隔删除记录 |

## 3. 读取哪些文件

只读取以下三个只读文件：

- `Data/00_原始数据_只读/final_filtered_21_modified.csv`
- `Data/00_原始数据_只读/final_filtered_22_modified.csv`
- `Data/00_原始数据_只读/final_filtered_23_modified.csv`

原始文件不会被改动。

如果农机编号、日期、开始时间或结束时间为空或无法读取，程序会停止。这些字段有问题时，无法可靠判断记录属于哪台农机或应排在什么位置。

## 4. 城市为空的5行怎样处理

代码在生成接续数据前删除这5行：

| 年份 | 删除行数 |
| ---- | -------: |
| 2021 | 1 |
| 2022 | 0 |
| 2023 | 4 |

删除后，同一台农机剩余的记录继续按时间排列。例如：

```text
A市 → B市 → [城市为空] → C市
```

删除后按下面的顺序处理：

```text
A市 → B市 → C市
```

这样做等于采用了“这5行是噪音，不代表一次需要保留的未知城市访问”这一判断。被删除的原始行号、农机编号和时间保存在`城市缺失删除记录.csv`中，可以随时回到原文件检查。

## 5. 怎样生成城市接续

1. 按农机编号和时间排列记录。
2. 删除城市为空的5行。
3. 把连续出现的同一城市合并为一次访问。
4. 对同一台农机的所有前后城市位置生成接续记录。
5. `边级`表示两个位置相隔几步：相邻位置是一级，中间隔1次访问是二级，以此类推。
6. `衰减权重=0.5^(边级-1)`。
7. 保留再次访问城市、直接回流、时间重叠等标记，供后面研究使用。

输出中继续保留`链段编号`列，是为了不改变已经建立的文件结构。按现在的规则，每台农机每年只有一条城市顺序，因此该列固定为1。

## 6. 代码会检查什么

- 输入文件、字段、行数和日期范围是否正确。
- 5行城市空值是否仍是2021年1行、2023年4行；数量改变时停止运行。
- 删除明细是否正好有5行。
- 连续同城是否已经合并。
- 输出边数是否符合公式。
- 每条记录的编号是否重复。
- 起点是否在终点之前，边级和权重是否正确。
- 输出文件能否正常读回。

## 9. 第一步补充统计与可视化

补充统计使用以下输入：

- `Data/03_有向边数据/2021年农机城市接续.csv`
- `Data/03_有向边数据/2022年农机城市接续.csv`
- `Data/03_有向边数据/2023年农机城市接续.csv`
- `Data/02_筛选后81城数据/citys_2023_1.csv`

81城按城市名称去掉首尾空格后精确匹配，不使用模糊匹配。

本次把“相邻下一站回到这台农机当年已经访问过的城市”记为一次直接回流。例如`A-B-C-D-C-E`中的`D→C`是一次直接回流，完整回流片段记为`C-D-C`。如果同一台农机随后再次返回同一城市，会另记一行。

该定义只用于本次查看数据。后续正式研究是否还要包含其他回访关系或同城端点，仍需单独决定。

补充输出如下：

- `Results/00_数据审计/边权重统计.csv`：75行，列出三年每个边级、权重、边数量和占比。
- `Results/00_数据审计/81城边范围统计.csv`：9行，列出三年三种81城范围类型的边数量和占比。
- `Results/00_数据审计/边权重数量.png`：不同边级和权重的边数量图。
- `Results/00_数据审计/81城边范围.png`：边两端是否属于81城的堆叠柱状图。
- `Results/00_数据审计/直接回流占比.png`：三年直接回流次数占当年一级边总数的比例图，柱顶标出“直接回流次数 / 一级边总数”。
- `Data/03_有向边数据/回流路径.csv`：51,303行，一行一次直接回流事件。

补充Notebook默认不覆盖已有结果。确认重跑时，在执行环境设置`CITY_EDGE_ANALYSIS_ALLOW_OVERWRITE=1`；代码会先备份旧结果，再生成新结果。
