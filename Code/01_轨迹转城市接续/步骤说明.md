## 1. 这一步做什么

这一步把每台农机的田间作业记录按时间排好，整理出它先后到过的城市，再生成前后城市之间的接续记录。

2021、2022、2023年分开处理，不会跨年连接。保留全部有名称的轨迹城市，不提前限制为81城。

输出只能说明城市出现的先后关系，不能证明农机一定从起点直接开到终点，也不能证明因果关系。

## 2. 主要设置

| 项目 | 当前设置 | 简单说明 |
| ---- | -------- | -------- |
| 年份 | 2021、2022、2023分开 | 同一台农机不跨年连接 |
| 城市范围 | 全部有名称的城市 | 不限于81城 |
| 城市为空的记录 | 删除 | 共5行；明细单独保存 |
| 删除后的连接方式 | 剩余记录继续按时间排列 | 删除行前后的有效城市可能重新相邻 |
| 连续同城 | 合并 | 连续多条同城记录算作一次访问 |
| 再次返回同城 | 保留 | 离开后再回来算作新的访问 |
| 权重 | 每远一级减半 | 一级为1，二级为0.5，三级为0.25 |
| 最大时间间隔 | 暂不设置 | 目前不因为时间间隔删除记录 |

## 4. 城市为空的5行怎样处理

代码在生成接续数据前删除这5行：

| 年份 | 删除行数 |
| ---- | -------: |
| 2021 | 1 |
| 2022 | 0 |
| 2023 | 4 |

删除后，同一台农机剩余的记录继续按时间排列。例如：

```text
A市 → B市 → [城市为空] → C市
```

删除后按下面的顺序处理：

```text
A市 → B市 → C市
```

这样做等于采用了“这5行是噪音，不代表一次需要保留的未知城市访问”这一判断。被删除的原始行号、农机编号和时间保存在`城市缺失删除记录.csv`中，可以随时回到原文件检查。

## 5. 怎样生成城市接续

1. 按农机编号和时间排列记录。
2. 删除城市为空的5行。
3. 把连续出现的同一城市合并为一次访问。
4. 对同一台农机的所有前后城市位置生成候选接续记录，保留离开后再次访问的城市位置。
5. `边级`表示两个位置相隔几步：相邻位置是一级，中间隔1次访问是二级，以此类推。
6. `衰减权重=0.5^(边级-1)`。
7. 输出全部候选接续及事实标记。本步骤不按负时间间隔或起终点同城删除边；这两类筛选在第二步完成。

输出中继续保留`链段编号`列，是为了不改变已经建立的文件结构。按现在的规则，每台农机每年只有一条城市顺序，因此该列固定为1。

- 连续同城是否已经合并。

- 每条记录的编号是否重复。
- 起点是否在终点之前，边级和权重是否正确。
- 输出文件能否正常读回。

## 12. 农机在各城市的累计作业时长
