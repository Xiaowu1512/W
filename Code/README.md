## 使用规则

1. 按表中顺序运行代码，先运行01A，再运行01B，最后运行02。
2. 运行具体步骤前，先阅读该步骤的说明文档。
3. 后一步依赖前一步输出时，不得跳过上游质量检查。
4. Notebook应能从头到尾独立运行，不依赖隐藏状态，也不得把核心处理逻辑放在项目内另建的`.py`模块中。
5. 新增、删除、合并或调整步骤顺序时更新本文件。
