# 项目入口

本文件只负责项目导航、阅读顺序和文档维护说明。AI的具体工作规则见`AGENTS.md`。

## 一、开始工作前的阅读顺序

AI在开始任何工作前，按以下顺序读取：

1. `Docs/研究模型与算法方案.docx`
2. `AGENTS.md`
3. `PLAN.md`
4. `DECISIONS.md`
5. `Data/数据字典.md`
6. `Data/data_manifest.csv`
8. `Docs/变量总表.md`
9. `Docs/数据流与文件依赖.md`
10. `Docs/待解决问题.md`
11. `Code/README.md`

非必要情况下不要阅读`Data`中除`data_manifest`以外的数据集文件，浪费时间。

任务涉及具体步骤时，再读取对应步骤的说明文档、Notebook、上游输入、质量报告和结果文件。

`Archive/`不属于默认必读目录。只有在追溯旧版本、恢复备份、核查版本差异或确认废弃原因时，才读取`Archive/README.md`及其指向的归档文件。

## 三、维护原则

1. 同一信息只保留一个正式说明位置，其他文件通过路径引用，不重复维护。
2. 阅读顺序写在`README.md`，AI行为规则写在`AGENTS.md`。
3. 当前进度写在`PLAN.md`，正式决定写在`DECISIONS.md`，尚未解决的问题写在`Docs/待解决问题.md`。
4. 数据内容写在数据字典，变量含义写在变量总表，文件上下游关系写在数据流与文件依赖文档。
5. 修改上游数据、定义或方法后，应同步检查所有下游代码、结果和说明文档是否需要更新。
6. 必要文档缺失、内容冲突或无法确定正式版本时，应停止运行并先向用户说明。
7. `Archive/`中的文件不得作为正式输入，非明确要求不读取除Archive的文件，但可以在修改代码或方案时进行写入旧代码或者方案，写入时需在文件名以及readme.md中加入旧代码的必要信息，如修改日期，修改内容等；需要恢复时，必须先核对归档说明和当前正式版本。
5. `Docs/变量总表.md`中的“代码变量名”必须与 Notebook 实际使用的英文变量名一致；中文名称另列为“中文含义”或“输出字段名”。
