# 数据流与文件依赖

## 总体数据流

```text
原始数据
  ↓
正式输入
  ↓
数据处理与质量检查
  ↓
中间结果
  ↓
正式结果
  ↓
论文图表与汇报材料
```

## 文件依赖

| 步骤 | 代码文件 | 上游输入 | 主要处理 | 输出文件 | 下游使用 |
| ---- | -------- | -------- | -------- | -------- | -------- |
| 01 轨迹转城市接续 | `Code/01_轨迹转城市接续/build_machine_city_edges.ipynb`；函数模块 `build_machine_city_edges.py` | `Data/00_原始数据_只读/final_filtered_21_modified.csv`、`final_filtered_22_modified.csv`、`final_filtered_23_modified.csv` | 分年稳定排序 → 城市缺失断链 → 连续同城合并 → 链段内全部有序访问位置对 → 边级与0.5衰减 → 回访和时间质控 → 理论计数与主键检查 | `Data/03_有向边数据/2021年农机城市接续.csv`、`2022年农机城市接续.csv`、`2023年农机城市接续.csv`；`Results/00_数据审计/城市接续审计.csv` | 城市对汇总、回流处理、基线链路构建 |

## 运行顺序

1. 运行`Code/01_轨迹转城市接续/build_machine_city_edges.ipynb`，先检查三年正式输入，再生成三份分年候选接续数据和审计表。

## 重新运行规则

- 上游正式数据变化后，重新运行所有依赖该数据的下游步骤。
- 变量定义、方法或阈值变化后，重新运行受影响步骤及其全部下游步骤。
- 只修改图表样式且数值未变化时，可以只重新运行对应可视化步骤。
- 三份 GNSS 任一文件、排序键、缺失断链规则、连续同城规则、边级或衰减公式变化时，必须重跑步骤 01 及全部下游步骤。
- 步骤 01 默认拒绝覆盖既有正式输出；确认重跑时启用覆盖参数，代码会先将现有输出备份至带时间戳的 `Archive` 子目录。
